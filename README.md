# news-service

Временный микросервис новостей. Берёт посты из паблика VK через VK API
и отдаёт их фронту в нашем формате. Когда появится настоящий бэкенд новостей,
он реализует тот же контракт (`GET /api/news`), а этот сервис выключат:
фронт менять не придётся.

Написан на Go, только стандартная библиотека, без внешних зависимостей.

## Как работает

```
Браузер ──GET /api/news──▶ news-service ──(раз в REFRESH_INTERVAL)──▶ VK API wall.get
                              │ отдаёт из памяти
                              ▼
                         Store (кеш)
```

- При старте и затем раз в `REFRESH_INTERVAL` (по умолчанию 1 час) сервис забирает посты из VK.
- Запросы фронта обслуживаются из памяти и не обращаются к VK.
- Если VK недоступен, остаются последние загруженные новости, а следующая попытка будет через `RETRY_INTERVAL`.
- Токен VK есть только на сервере и не уходит в браузер.

## API

Полный контракт — `internal/api/openapi.yaml` (OpenAPI 3). Сервис показывает его в Swagger UI
по адресу `/api/docs`, сама спецификация лежит на `/api/docs/openapi.yaml`.

Формат новости совпадает с TS-типом фронта:

```ts
type TNews = {
  id: string;              // slug: "den-otkrytykh-dverey-512"
  images: string[] | null; // всегда массив; [] если картинок нет
  type: TNewsType | null;  // в VK типов нет, поэтому всегда null
  date: string;            // ISO 8601, UTC
  title: string;
  text: string | null;     // null, если кроме заголовка текста нет
};
```

### `GET /api/news?limit=10&offset=0`

`limit` по умолчанию 10, максимум 50. `offset` по умолчанию 0.

```json
{
  "items": [
    {
      "id": "den-otkrytykh-dverey-v-politekhe-512",
      "images": ["https://sun9-....userapi.com/...jpg"],
      "type": null,
      "date": "2026-10-18T13:00:00Z",
      "title": "День открытых дверей в Политехе!",
      "text": "Приходите 1 ноября."
    }
  ],
  "total": 12,
  "updated_at": "2026-10-18T13:05:00Z"
}
```

Новости идут от новых к старым. Реклама, репосты и посты без текста отфильтрованы.

### `GET /api/news/{slug}`

Возвращает одну `TNews`, если такой нет — `404`. Число в конце slug — это номер поста в VK.
Если пост отредактировали и slug поменялся, старая ссылка всё равно откроет новость.

### `GET /health`

`{"status":"ok","news_loaded":true,"updated_at":"..."}`: проверка, что сервис жив.

### Ошибки

`{"error": "..."}`:

| Код   | Когда                                        |
|-------|----------------------------------------------|
| `400` | Неверные параметры                           |
| `404` | Новость не найдена                           |
| `503` | После старта ещё не было ни одной загрузки   |

### Как пост VK превращается в новость

- **Заголовок.** Если первая строка поста не длиннее 100 символов, она становится `title`, а остальной текст идёт в `text`. Если первая строка длиннее, `title` — это первые ~100 символов без разрезания слова плюс `...`, а `text` — весь пост.
- **Упоминания** `[club123|Название]` превращаются в просто «Название».
- **Картинки.** VK присылает каждое фото примерно в 10 копиях. Обрезанные превью (`o/p/q/r`) отбрасываются. Берётся копия `z` (до 1080×1024 с исходными пропорциями, обычно 100–300 КБ), а если её нет, то следующая по качеству. Получается одна ссылка на каждое фото поста.

## Настройки (переменные окружения)

| Переменная         | Обязательная | По умолчанию | Описание |
|--------------------|:---:|---|---|
| `VK_SERVICE_TOKEN` | да  | — | Сервисный ключ приложения VK |
| `VK_GROUP`         |     | `spp_polytech` | Короткое имя паблика (`spp_polytech`) или id со знаком минус (`-12345`) |
| `REFRESH_INTERVAL` |     | `1h` | Как часто обновлять: `30m`, `1h`, `3h` |
| `RETRY_INTERVAL`   |     | `5m` | Повтор после ошибки |
| `PORT`             |     | `8080` | Порт сервиса |
| `VK_API_VERSION`   |     | `5.199` | Версия VK API |
| `VK_POSTS_COUNT`   |     | `100` | Сколько последних постов брать (1–100) |
| `CORS_ORIGIN`      |     | пусто | Адрес фронта, если он на другом домене или порту |
| `LOG_FILE`         |     | пусто | Файл, куда дублировать логи; пусто — только stdout |

### Как получить токен

1. Создать приложение на https://dev.vk.com (тип «Веб» или «Standalone»).
2. В его настройках скопировать **сервисный ключ доступа**.
3. Положить ключ в `VK_SERVICE_TOKEN`. Паблик должен быть открытым.

## Запуск локально (Windows, PowerShell)

```powershell
copy .env.example .env   # и заполнить VK_SERVICE_TOKEN
go run .
# проверить: http://localhost:8080/api/news
```

Тесты: `go test ./...`

## Docker

```bash
docker build -t news-service .
docker run --env-file .env -p 8080:8080 news-service
```

Фрагмент для `docker-compose.yml` рядом с бэкендом:

```yaml
  news:
    build: ./news-service
    env_file: ./news-service/.env
    restart: unless-stopped
    # ports: ["8080:8080"]   # не нужно, если наружу выходит через nginx
```

Если перед сервисами стоит nginx, нужен такой блок:

```nginx
location /api/news {
    proxy_pass http://news:8080;
}

# Swagger UI; можно не открывать в проде
location /api/docs {
    proxy_pass http://news:8080;
}
```

Если фронт и API на одном домене, `CORS_ORIGIN` не нужен.

## Структура

```
main.go                    сборка всех частей и запуск/остановка HTTP-сервера
internal/config/           чтение настроек из окружения и .env
internal/news/news.go      модель News (контракт API = TNews) и интерфейс Source
internal/news/slug.go      генерация slug из заголовка
internal/news/store.go     хранилище новостей в памяти (потокобезопасное)
internal/news/updater.go   фоновое обновление по таймеру
internal/vk/client.go      запрос к VK API wall.get
internal/vk/types.go       структуры ответа VK
internal/vk/convert.go     перевод постов VK в News (адаптер)
internal/api/handlers.go   HTTP-эндпоинты для фронта
internal/api/docs.go       Swagger UI на /api/docs
internal/api/openapi.yaml  спецификация API (OpenAPI 3), встроена в бинарник
```

Вся работа с VK собрана в пакете `internal/vk`. Остальной код знает только
интерфейс `news.Source`, поэтому источник можно заменить, не трогая API.
